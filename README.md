# EduShift — Staff Scheduling Android App

EduShift is an Android application designed to simplify staff scheduling and teacher availability management. It helps administrators organize schedules and allows teachers to manage their availability and leave requests.

## Features

- **Admin Dashboard:** Manage staff schedules and assignments.
- **Schedule Management:** Create, update, and manage staff schedules.
- **Teacher Availability:** Teachers can mark schedules as completed or report unavailability.
- **Leave Requests:** Submit and manage teacher leave requests.
- **Announcements:** Share important updates with teachers.
- **Push Notifications:** Receive relevant updates and announcements.

## Tech Stack

- **Language:** Java
- **UI:** XML
- **IDE:** Android Studio
- **Backend:** Firebase
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Notifications:** Firebase Cloud Messaging (FCM)

## Project Setup

1. Clone this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase project.
4. Add your Firebase configuration file at `app/google-services.json`.
5. Sync Gradle and run the app on an Android emulator or device.

## Security Notice

Firebase configuration files and local development settings are excluded from this repository. Configure your own Firebase project before running the application.
